# 失败案例记录（面试必讲：失败 → 定位 → 修正）

> 面试官最常追问的就是失败和调优过程。下面 3 个是 Agent 项目的高发坑，
> 每个案例的结构是：现象 → 复现 → 定位 → 修正 → 效果。
> **要求：跑完真实链路后，把"定位"和"效果"换成你自己的实测数据与说法，
> 面试讲"我的经历"而不是"通用经验"。**

## 案例 1：检索不准，答非所问

- **现象**：问"A 主题"，模型回答里混进 B 主题的内容，或答不到点上。
- **复现问题**：用 20 个标注测试问题跑检索，观察命中片段与期望段落不一致。
- **定位**：先查切片——chunk 太大（如 500 字）时，一个片段里混了两段主题，检索分数被稀释；chunk 太小（如 100 字）时，上下文被切断，关键词命中但语义不完整。
- **修正**：改为"段落优先 + 超长段按字符切 + 重叠"；把 CHUNK_SIZE 从 ____ 调到 ____，CHUNK_OVERLAP 设 ____。
- **效果**：20 题 top-3 命中率从 ____% 提升到 ____%。
- **一句话总结（面试版）**：____

## 案例 2：幻觉——检索不到也硬答

- **现象**：知识库没有的内容，模型一本正经编出来，还编得像模像样。
- **复现问题**：问一个语料外的冷门问题，模型直接回答而非承认不知道。
- **定位**：system prompt 没有约束 + 检索结果没有作为"引用来源"展示，模型无从判断哪些是检索到的。
- **修正**：system prompt 加规则"检索结果中没有依据时，明确回答不知道"；工具返回带来源索引；对低分命中（score 接近 0）做过滤。
- **效果**：____ 个语料外问题的"硬答率"从 ____% 降到 ____%。
- **一句话总结（面试版）**：____

## 案例 3：工具调用失败——格式错 / 未知工具 / 参数错

- **现象**：模型输出的工具调用解析失败，或调用了不存在的工具名。
- **复现问题**：连跑 10 个问题，统计工具调用失败次数。
- **定位**：模型偶尔输出非标准 JSON；参数缺字段；工具名写错。
- **修正**：参数解析加 try/except 容错（解析失败按空参数处理并返回错误观察）；工具名走白名单字典查不到即拒绝；执行函数整体捕获异常转成工具返回值，不中断循环。
- **效果**：工具调用成功率从 ____% 提升到 ____%。
- **一句话总结（面试版）**：____
