# 使用说明

## 1. 安装与配置

```bash
pip install -r requirements.txt
copy .env.example .env     # Windows；Linux/macOS 用 cp
```

编辑 `.env`：
- `API_KEY`：必填（真实运行时）。DeepSeek 在 platform.deepseek.com 注册并充值（充值最低 10 元，足够跑几百次问答）
- `LLM_PROVIDER`：`deepseek` 或 `qwen`
- 无 Key 调试：`python -m app.agent "问题" --mock`（Mock 模式），或把 `.env` 里 `MOCK_MODE=1`

## 2. 运行

| 场景 | 命令 |
|---|---|
| 无 Key 演示 | `python -m app.agent "什么是MCP？" --mock` |
| 真实问答 | `python -m app.agent "什么是MCP？"` |
| 图形界面 | `pip install -r requirements-ui.txt` 后 `streamlit run ui/app.py` |
| LangChain 版 | `pip install -r requirements-framework.txt` 后 `python langchain_version/agent_lc.py` |
| 测试 | `python tests/test_react.py` |

## 3. 换成语料（正式项目必做）

1. 把 `.env` 的 `CORPUS_PATH` 改成你的文档路径（.md / .txt，UTF-8）
2. 建议语料规模：1~5 份文档、10KB~1MB；太大先挑核心章节
3. 换完后跑 `python -m app.agent "一个你文档里的问题"` 验证检索命中
4. 面试前把语料换成你最熟的文档（技术笔记/课程资料/产品说明书），才能讲深

## 4. 调优指南（检索不准时按顺序查）

| 变量 | 位置 | 影响 | 调整方向 |
|---|---|---|---|
| CHUNK_SIZE | .env | 切片粒度 | 太大→片段混杂，调小（如 300→200）；太小→上下文断裂，调大 |
| CHUNK_OVERLAP | .env | 片段衔接 | 一般取 chunk 的 10%~20% |
| TOP_K | .env | 返回条数 | 命中但条数少→调大（3→5）；噪声多→调小 |
| 分词 | retriever.py | 中文切词 | 领域词被切碎→加 jieba 自定义词典 |

每次只改一个变量，用同一批测试问题重测，记录命中率变化。

## 5. 评测方法（面试必讲）

1. 构造 20~30 个测试问题，每题标注期望命中的段落（真值）
2. 跑检索，算 top-3 命中率 = 命中数 / 总题数
3. 调参前后对比，记录在 `docs/失败案例记录.md`
4. 人工核对回答准确率（正确答案由语料决定，不依赖 LLM 打分，可解释）

## 6. 升级路径：BM25 → 向量检索

当前 BM25 零成本可解释，适合小语料。升级方案：
- 通义百炼 `text-embedding-v3/v4`（或 bge-m3 本地模型）把切片向量化，用余弦相似度检索
- 检索后再加一个重排序（rerank）模型，或让 LLM 对 top-k 重排
- 语料超过几百份文档时再上向量库（如 Chroma/FAISS），之前不用

升级时只需替换 `app/rag/retriever.py` 里的 `BM25Index.search()`，对外接口不变。

## 7. 成本估算

- DeepSeek 按 token 计费，价格随官方调整（以官网为准）。单次问答通常 1~3 千 token 量级，一次完整演示成本在**几分钱**量级
- 评测 30 题全跑一遍，成本约几毛钱量级；先用 Mock 模式验证逻辑，再上真实调用省钱

## 8. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `缺少 API_KEY` | .env 没配 Key，或没复制 .env.example |
| 报错 401/403 | Key 填错、账号未充值、供应商选错（BASE_URL 与 provider 不匹配） |
| 报错 429 | 限流，等几秒重试 |
| 控制台中文乱码 | PowerShell 里先执行 `$env:PYTHONIOENCODING='utf-8'`，或用 `python -X utf8` |
| jieba 首次运行慢 | 首次要构建词典缓存，属正常，第二次就快了 |
| 语料不存在 | CORPUS_PATH 路径写错，用绝对路径最稳 |
